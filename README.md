# Deer Crossings development graph

This public repository hosts the Deer Crossings version graph. The historical files remain in the [private repository](https://github.com/notserps/assetto-corsa-deer-mod), so the version-tree file buttons require access. The current alpha is available in the [public release repository](https://github.com/notserps/deer-crossings/releases/tag/v1.0.0-alpha.1).

[Open the interactive graph](https://notserps.github.io/deer-crossings-graph/) · [Download the current alpha](https://github.com/notserps/deer-crossings/releases/tag/v1.0.0-alpha.1)

Drag to pan, scroll to zoom, search by version or feature, and select a node for its description and links to the private files and exact version tag.
