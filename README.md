# Deer Crossings development graph

This public repository hosts an interactive graph of the 121 retained versions in the Deer Crossings development history. It contains version names and descriptions only. The original mod source, packages, and assets remain in the [private archive](https://github.com/prestoncaisse/assetto-corsa-deer-mod), and file buttons require access to that repository.

[Open the interactive graph](https://prestoncaisse.github.io/deer-crossings-graph/)

Drag to pan, scroll to zoom, search by version or feature, and select a node for its description and links to the private files and exact version tag.
